# 产品规格说明

## 产品定位

- **名称**：咪咕医生
- **目标用户**：宠物出现不适、疑似误食，或需要查询日常养护信息的宠物主
- **核心任务**：帮助用户把信息说清楚、识别紧急程度、理解下一步行动
- **平台**：移动端优先的本地 Web MVP
- **安全定位**：风险提示与就医分流工具，不做诊断或处方

## 核心流程

1. 首页选择症状初筛、误食风险或养宠百科。
2. 症状初筛先检查危险信号，再分步采集宠物与症状信息。
3. 非紧急情况由 AI 提出 2–3 个关键追问，再生成结构化风险提示。
4. 危险信号、高危误食或信息不足时固定引导联系宠物医院。
5. 所有页面持续展示“不构成诊断”的边界说明。

## 已实现范围

- 首页与三条主入口
- 三步症状采集
- 危险信号确定性分流
- AI 追问与风险结果
- 误食风险信息采集
- 健康百科
- 医院导航入口
- 本地 API 代理、超时/错误反馈、安全文本渲染
