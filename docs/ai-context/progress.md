## 当前已知限制

- [ ] 尚未由执业兽医正式复核危险信号、三段阈值、误食规则和服务端提示词
- [ ] 自动化测试未覆盖完整浏览器端到端流程、视觉截图和真实设备矩阵
- [ ] 未验证真实 DeepSeek 账号、额度和网络在演示现场的可用性
- [ ] 地图搜索不能验证医院距离、营业时间或接诊能力
- [ ] 当前只支持猫狗，不支持异宠
- [ ] 没有账号、云数据库、多宠物档案和跨设备同步
- [ ] 本地 Python 服务不是生产服务器，不具备公网认证、限流、TLS、监控或合规数据保护
